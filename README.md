# Server UI Plugin для Rust

Плагин для создания красивого пользовательского интерфейса сервера Rust с русской локализацией, основанный на изображении интерфейса.

## Особенности

- 🎨 Современный темный интерфейс в стиле оригинального изображения
- 🇷🇺 Полная русская локализация
- 📱 Интеграция с социальными сетями (Telegram, Discord, VK)
- 📊 Отображение статистики сервера в реальном времени
- 📅 Календарь вайпов
- 🎁 Система GRANDPASS с прогрессом опыта
- 🏠 Навигационное меню с разделами

## Установка

1. Скопируйте файл `ServerUIPlugin.cs` в папку `oxide/plugins/` вашего сервера
2. Скопируйте файл `ServerUIPlugin.json` в папку `oxide/config/` (опционально, для настройки)
3. Перезагрузите плагин командой `oxide.reload ServerUIPlugin`

## Команды

### Чат команды
- `/ui` - Открыть главный интерфейс
- `/closeui` - Закрыть интерфейс

### Консольные команды
- `serverui.menu <раздел>` - Переключение между разделами меню
- `serverui.social <платформа>` - Открытие ссылок на социальные сети

## Конфигурация

Плагин автоматически создает конфигурационный файл `ServerUIPlugin.json` со следующими настройками:

```json
{
  "ServerName": "Название вашего сервера",
  "ResourceMultiplier": 2,
  "TelegramUrl": "https://t.me/your_channel",
  "DiscordUrl": "https://discord.gg/your_server",
  "VkUrl": "https://vk.com/your_group",
  "NextWipeDate": "02.10.25",
  "Localization": {
    // Все текстовые строки для локализации
  }
}
```

## Разделы интерфейса

### Боковое меню (GRANDPASS)
- 🏠 **ГЛАВНАЯ** - Основная информация о сервере
- ℹ️ **ИНФОРМАЦИЯ** - Информация о сервере
- 🎒 **НАБОРЫ** - Игровые наборы
- 📅 **ЕЖЕДНЕВКИ** - Ежедневные задания
- 🎁 **КЕЙСЫ** - Система кейсов
- 🚫 **БЛОКИРОВКА** - Управление блокировками
- ⚙️ **ПРИ** - Настройки
- 📊 **СТАТИСТИКА** - Статистика игрока
- 🛒 **КОРЗИНА** - Корзина покупок

### Главная панель
- Название и описание сервера
- Информация о команде игрока
- Множитель ресурсов
- Статистика онлайн игроков
- Настройки социальных сетей
- Календарь вайпов

## Функциональность

### Статистика игроков
- Отображение количества игроков онлайн
- Показ подключающихся игроков
- Информация об очереди (если есть)

### Социальные сети
- Кнопки для привязки аккаунтов Telegram, Discord, VK
- Настраиваемые ссылки в конфигурации

### Календарь вайпов
- Отображение даты следующего вайпа
- Информация о предыдущих вайпах
- Простой календарь на месяц

### Система GRANDPASS
- Отображение текущего опыта (30 EXP из 100)
- Иконка награды "СКОРО"
- Прогресс-бар (планируется)

## Кастомизация

Вы можете легко настроить плагин под свой сервер:

1. **Цвета интерфейса** - измените значения цветов в коде
2. **Локализация** - добавьте или измените переводы в конфигурации
3. **Ссылки соц. сетей** - укажите свои ссылки в конфиге
4. **Название сервера** - настройте в конфигурации
